# be-ruby: a journal

A Temper backend for Ruby, written in the open, with types. This directory
is the running record: one entry per working session, newest last, plus a
guide that grows as the backend does.

- [guide.md](guide.md) -- how the backend works as it stands, and what it
  cannot do yet.
- [probes/](probes/) -- the Ruby scripts every claim about the target was
  checked with. Run any of them with `ruby probes/<file>.rb`. They were
  written against ruby 4.0.7.
